// agent mode

Delegate the task, review the diff.

Agent mode plans multi-file changes, executes them step by step, runs your checks and hands you a summary. Nothing merges without your approval.

  • Planning first — see the intended edits and estimated scope before anything runs.
  • Cross-file edits — refactors that touch controllers, services and tests together.
  • Self-checks — the agent runs analysis and tests, then reports honestly.
agent session
// task
agent "add retry logic to the chat engine"

// plan (approved)
1. chat_engine.dart  — wrap stream in bounded retry
2. backoff.dart      — new: exponential backoff helper
3. engine_test.dart  — cover StreamDropped path

// result
✓ 3 files changed · analysis clean · tests 14/14

Your codebase, your call.

Every AI edit is a reviewable diff. Accept, reject or refine hunk by hunk — with keyboard shortcuts, straight from the editor.

  • Hunk-level control — take the good parts, drop the rest.
  • Refine in place — ask for a different approach without losing context.
  • Full undo — every applied change is one keystroke from reverted.
