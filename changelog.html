We ship every few weeks. Subscribe in the footer and we'll send you the highlights — never more than one email per release.

v1.4.0 Latest July 10, 2026

Agent mode & MCP marketplace

  • NewAgent mode — delegate multi-file tasks; the agent plans, edits, runs checks and reports back with reviewable diffs.
  • NewMCP tool marketplace — browse and install Model Context Protocol servers without editing JSON.
  • NewInline diff review v2 — hunk-level accept/reject/refine with keyboard shortcuts.
  • ImprovedCold start is 38% faster; the editor is interactive before AI services finish warming up.
  • FixedCommand palette no longer loses focus when a background task completes.
v1.3.2 June 21, 2026

Stability patch

  • FixedMemory leak in sessions longer than two hours — controllers now dispose cleanly.
  • FixedVoice input occasionally captured the first word twice on slower microphones.
  • ImprovedReduced idle CPU usage by batching status bar updates.

The IDE update

  • NewCommand palette (Ctrl+Shift+P) with fuzzy search across files, commands and settings.
  • NewGit panel — stage, commit, branch, history, with AI-written commit messages.
  • NewNotification, task and log panels; status bar with live engine state.
  • NewExplorer context menus with rename, reveal and safe delete.
  • ImprovedTheme system rebuilt on semantic tokens — custom themes coming later.
