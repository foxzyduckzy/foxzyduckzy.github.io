v1.0.0 Latest First public release

The first build you can install

  • NewAgent mode — describe a task and Loopable8 plans it, edits the files, runs the commands and checks its own output.
  • NewManual and Auto approval — Manual reviews every edit and risky command before it lands; Auto applies them for you.
  • NewRewind — one click restores every file a run touched.
  • NewLoopDrive — set how hard a run works, from Sprint through Precision.
  • NewBuilt-in terminal, live app preview and a Workflow panel showing the working-tree diff.
  • NewMCP servers, your own custom commands as agent tools, and saved SSH hosts.
  • NewCommand palette, project-wide search and replace, and a file explorer.

Loopable8 is in early preview and under active development. Later releases will be listed here as they ship — this page only records builds that actually exist.
