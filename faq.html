Product

An AI coding assistant for Windows: an editor with agent mode, inline diff review, MCP tools, git integration and the LO8 model family. AI Chat, AI Studio (image/video/voice) and an AI-native game dev studio are in development on the same platform.

You describe a task; the agent proposes a plan, edits across files after you approve, runs analysis and tests, then presents everything as reviewable diffs. Nothing is final until you accept it.

The AI works with any text; first-class experiences (syntax highlighting, analysis integration) cover Dart/Flutter, C#, C++, JavaScript/TypeScript, Python, HTML/CSS and more each release.

AI Chat targets Q4 2026. AI Studio is in research; the Game Dev Studio is at prototype stage. We publish honest status on the roadmap and announce dates only when we're sure. Pro members get every beta first.
