// the story

Started as a chat app. Became a studio.

Loopable8 began as an AI chat application — a place to think with a model that respected your settings. Then we noticed where all our time actually went: inside the editor. So we rebuilt Loopable8 around code first.

The coding assistant shipped in March 2026 and has moved fast since — agent mode, inline diffs, MCP tools. The rest of the vision (chat, media generation, an AI-native game dev studio) is on the same foundation, arriving as each piece earns its place.

// what we believe

Values we actually use.

Control is a feature

Temperature, thinking level, tools, memory — you set it, the engine obeys it. AI you can't steer is a toy.

Local first

Conversations, memory and settings live on your machine. Deleting them is one click, and it's real.

Honest shipping

"Coming soon" means we're building it, not teasing it. The changelog is the only marketing we fully trust.

Build with us.

Try the assistant, tell us what's broken, and shape what ships next. The loop works better with you in it.
