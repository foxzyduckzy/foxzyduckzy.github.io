The mono was consolidated on purpose. Call sites used to pick their own — Roboto Mono in most places, JetBrains Mono in a few — so the same kind of content rendered in two different fonts: a code block in chat did not match the code stream in the right panel. JetBrains Mono won because it is drawn for code and it is what the website already declared.
