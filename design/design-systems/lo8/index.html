Design

One token source, generated for every surface. tokens.json is the only place a value is decided; tokens.css and brand.dart are both outputs. Neither can drift from the other, because neither is the source.

The five principles

what to do when the table has no answer

One colour against the grey

The neutral ramp does all the layout work. The accent marks primary action and key data. Nothing else gets to be a colour — a neutral ramp exists so that one colour can mean something.

Chrome recedes, work advances

The pane you work in is the brightest surface; every panel around it sits back. Light mode always read that way. Dark mode had it inverted, with the chrome the brightest thing on screen and the work sitting in a well.

Tokens or nothing

No private copy of a palette value anywhere — not in a widget, not in a WebView’s HTML, not in a marketing site’s stylesheet. Four hard-coded hexes once left a seam down the middle of the app.

Typography is the design

Two faces, one prose size, hierarchy carried by colour. If a screen needs a third font or a seventh size, the screen is wrong, not the scale.

Hand-drawn against machine-made

The one deliberately imperfect thing in an otherwise exact system is the mark, and it is imperfect on purpose. Craft is the whole argument of the brand.
