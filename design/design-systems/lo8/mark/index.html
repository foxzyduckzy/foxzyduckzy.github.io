Identity

The mark

A lemniscate, the ∞ that is also the 8. It carries the whole name in one shape: the loop of Loopable, the 8 of 8.

Construction

Three overlapping pencil passes, not one clean path. All three run through an SVG feTurbulence + feDisplacementMap filter, that filter is what makes it read as graphite on paper rather than as vector.

The boil

proposal, not shipped

Why it is not shipped

Nothing in any of the four logo files animates. No <animate>, no @keyframes, no CSS animation; seed is fixed at 8. The three paths carry classes a, b, c, animation hooks that were never connected to anything. The signature of the brand was named and then left unbuilt.

The implementation above swaps between pre-seeded copies of the pencil filter with a CSS animation on step-end timing. CSS rather than SMIL specifically so prefers-reduced-motion stops it, a logo that jitters at someone who asked for stillness is a worse bug than a logo that does not move.

Colour

open decision

The mark on this page is drawn in currentColor, so one file serves both themes and adds nothing to the palette. The shipped assets are four files carrying two hard-coded stroke values between them:

#454956on light#F4F2EAon dark

Those two are the only tinted colours left in a provably neutral brand. Either the mark is a sanctioned exception, or the values come onto the ramp, and if the mark inherits currentColor the question disappears, because it stops having a colour of its own at all.

Rules

  • Never redraw it clean. A smooth lemniscate is a different, worse logo.
  • Never fill it. It is a stroke.
  • The boil is for hero, splash, loading and video. Static everywhere it would compete with content, sidebar, tray, favicon, titlebar.
  • Check it at 16px. Three overlapping pencil strokes will mud at favicon and tray sizes; that needs a purpose-drawn small variant, which does not exist yet.
