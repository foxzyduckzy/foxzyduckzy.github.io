Install from the terminal Preview

PowerShell · Windows 10/11

Downloads the latest build, checks its SHA-256, installs it for your user and adds a Start Menu shortcut. This is an early preview — features are still landing, so expect rough edges.

  1. Open PowerShell Press Win + X, then choose Terminal or Windows PowerShell. Admin is not required.
  2. Run the installer
    irm https://foxzyduckzy.github.io/install.ps1 | iex
  3. Launch it Open Loopable8 from the Start Menu — or run & "$env:LOCALAPPDATA\Programs\Loopable8\Loopable8.exe"

To remove it later:

irm https://foxzyduckzy.github.io/install.ps1 | iex -Uninstall
