Documentation

Everything you need to install Loopable8, understand the engine and get productive in your first hour.

Installation

Loopable8 currently ships for Windows 10 (1903+) and Windows 11, 64-bit. macOS and Linux builds are planned — see the download page to get notified.

  1. Download the installer from the download page.
  2. Run Loopable8-Setup-1.4.0.exe and follow the wizard.
  3. Launch Loopable8 — the editor works immediately; AI features connect on first prompt.
Loopable8 installs per-user and never requires administrator rights.

Quickstart

Open a folder with Ctrl O, then try these three moves:

1. Ask about your code

you> what does chat_engine.dart actually do?

The assistant reads the open file and project context before answering.

2. Make an edit

you> add null-safety guards to send()

The change arrives as an inline diff — accept it with A.

3. Delegate a task

you> /agent make the retry logic configurable from run settings

Agent mode plans the change, edits across files, runs analysis and reports back.

The interface

Three panels, one loop:

  • Explorer (left) — files, git status, timeline of AI edits.
  • Editor (center) — tabs, syntax highlighting, inline diffs.
  • AI panel (right) — conversation, agent progress, run settings.

The status bar shows engine state, analysis results and cursor position. Panels toggle from the command palette or Ctrl B.

Run settings

The right-hand panel is the source of truth: whatever it shows is exactly what the engine reads on the next run.

SettingWhat it does
Temperature0.0 = deterministic, 2.0 = exploratory. Default 1.0.
Thinking levelOff / Low / Mid / High / Max — how much reasoning happens before the answer.
System instructionsTone and style rules applied to every run in the workspace.
Grounding with SearchBack answers with live search results.
Save MemoryLet the assistant remember project facts across chats.
Settings are per-workspace and persist across restarts. Reproducibility rule: same settings + same prompt = same behavior class.

Agent mode

Agent mode turns a task description into a reviewed change:

  1. Plan — the agent lists intended edits and estimated scope. You approve.
  2. Execute — edits land file by file with live progress in the AI panel.
  3. Verify — the agent runs analysis/tests it can find and reports results honestly.
  4. Review — everything arrives as inline diffs; nothing is final until you accept.

Start it with /agent <task> or the palette command Agent: New Task. Free plans include 25 runs monthly; Pro is unlimited.

Inline diffs

Every AI edit is a diff you review in place:

KeyAction
AAccept hunk
RReject hunk
ERefine — describe what to change about this hunk
N / PNext / previous hunk
Ctrl+ZRevert an accepted change

MCP tools

Loopable8 speaks the Model Context Protocol. Install servers from the marketplace (palette → MCP: Marketplace) or add your own:

{
  "servers": {
    "github": {
      "command": "npx",
      "args": ["-y", "@modelcontextprotocol/server-github"]
    }
  }
}

Connected tools appear in run settings as toggles. The model calls them mid-conversation via function calling; every call is logged in the task panel.

Free plans connect up to 3 servers. Pro removes the limit and allows custom local servers.

Memory & privacy

Conversations and memory live locally on your machine. Two toggles control everything:

  • Save Conversations — keep chat history between sessions.
  • Save Memory — let the assistant remember durable project facts.

Clear Memory wipes stored facts instantly. Uninstalling removes all local data. See the Privacy Policy for what leaves your machine (prompts to the model API — nothing else).

Troubleshooting

The AI panel says "engine offline"

Check your internet connection, then palette → Engine: Reconnect. Corporate proxies: allowlist *.loopable8.com.

Voice input doesn't hear me

Windows Settings → Privacy → Microphone → allow desktop apps. Then re-select your mic in run settings → Voice.

Analysis is slow on a big repo

Add build folders to .lo8ignore (same syntax as .gitignore). The indexer skips them on the next scan.

Something else?

Check the FAQ or contact support — include the log from palette → Logs: Export.
